# RAGE
A minimal load testing tool written in rust for achieving maximum possible efficiency and the ease of use

<img src="RAGE.png"/>

# Implemented Features
1. Multi user management
2. TPS threshold
3. All types of REST APIs
4. CSV Reporting
5. Realtime CMD Reporting
6. Custom Headers

# Usage
1. Configure your test\
Use `test.yaml` to define all your test configurations

2. ```cargo run --release```

3. Analyse results from the output CSV
